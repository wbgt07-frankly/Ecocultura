# АгрономФото — Промо-сервис «Стань агрономом»

## Суть проекта

Интерактивный промо-сервис для бренда свежих томатов «ЭКО-культура».
Пользователь сканирует QR-код на мероприятии, загружает своё фото и получает брендированную открытку, на которой он изображён в роли агронома в теплице.

---

## Пользовательский путь

```
QR-код → Лендинг → Загрузка фото → Выбор базового образа → Генерация → Скачивание
```

1. **Сканирование QR-кода** — пользователь попадает на мобильную веб-страницу
2. **Загрузка фото** — селфи или любое фото с лицом
3. **Выбор персонажа** — агроном-мужчина или агроном-женщина (2–4 варианта поз/фонов)
4. **Генерация** — сервер делает face swap: лицо пользователя накладывается на базовое фото
5. **Результат** — пользователь видит итоговое фото и скачивает его на телефон

> Фото пользователей **не хранятся** — обрабатываются в оперативной памяти и удаляются сразу после отдачи результата.

## Базовые изображения

Нужно подготовить **4–6 базовых фото** (генерируются / снимаются до запуска):

| # | Персонаж | Сцена |
|---|----------|-------|
| 1 | Агроном-мужчина | Теплица, ряды томатов, рабочий планшет |
| 2 | Агроном-мужчина | Теплица, крупный план куста с плодами |
| 3 | Агроном-женщина | Теплица, ряды томатов, улыбается |
| 4 | Агроном-женщина | Теплица, держит спелый томат |

Требования к базовым фото:
- Лицо чётко видно, смотрит в камеру (для точного face swap)
- Хорошее освещение, нейтральный фон теплицы
- Брендированный фартук / рабочая одежда с логотипом ЭКО-культуры
- Разрешение не менее 1080×1350 px (портретный формат для мобильных)

## Брендинг

- Логотип бренда размещается на итоговом фото (угол или нижняя полоса)
- Фирменные цвета и шрифты — на лендинге и в UI
- Слоган / хэштег на финальной карточке (например: `#ЭКОагроном`)
- Все экраны выдержаны в фирменном стиле

---

## Технический стек

### Фронтенд
- **Vanilla HTML / CSS / JavaScript** — мобильный лендинг, без фреймворков
- Адаптирован под смартфоны (mobile-first)
- Загрузка фото через `<input type="file" accept="image/*" capture="user">`

### Бэкенд
- **Python + FastAPI** — REST API для обработки изображений
- **InsightFace** (библиотека face swap с открытым кодом) — наложение лица
- Обработка полностью в памяти (`BytesIO`), файлы на диск не пишутся
- Отдача результата как `image/jpeg` или base64 в JSON

### Инфраструктура
- **Деплой**: Railway или Render (бесплатный tier достаточен для промо-акции)
- **QR-код**: статическая ссылка на задеплоенный сервис, генерируется один раз
- **HTTPS**: обязателен (браузер требует для доступа к камере)

### Зависимости Python
```
fastapi
uvicorn
insightface
onnxruntime
pillow
python-multipart
```

## API

### `POST /api/swap`

**Request** — multipart/form-data:
| Поле | Тип | Описание |
|------|-----|----------|
| `user_photo` | file | Фото пользователя |
| `base_id` | string | ID базового изображения (`male_1`, `female_1`, …) |

**Response** — `image/jpeg` (готовое фото) или JSON с base64

---

## Ограничения и безопасность

- Максимальный размер загружаемого файла: **5 МБ**
- Принимаются только `image/jpeg`, `image/png`, `image/webp`
- Rate limiting: не более **10 запросов в минуту** с одного IP
- Никаких cookies, авторизации и аналитики пользователей — анонимный сервис
- Лица пользователей **не логируются и не сохраняются**
