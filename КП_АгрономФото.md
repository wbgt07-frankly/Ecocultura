# Коммерческое предложение

**Проект:** АгрономФото — интерактивный промо-сервис «Стань агрономом»
**Заказчик:** ЭКО-культура
**Исполнитель:** Владимир Богатырёв
**Дата:** апрель 2025

---

## О проекте

Интерактивный промо-сервис для бренда свежих томатов **ЭКО-культура**.

Пользователь сканирует QR-код на мероприятии, переходит на мобильную веб-страницу, загружает своё фото — и получает брендированную открытку, на которой он изображён в роли агронома в теплице бренда. Технология замены лиц (face swap) работает автоматически, в режиме реального времени.

Сервис не требует установки приложения. Работает в любом браузере смартфона.

**Пользовательский путь:**

```
QR-код → Лендинг → Загрузка фото → Выбор образа → Генерация → Скачивание
```

## Итоговый результат

По завершении проекта заказчик получает:

- Готовый к работе веб-сервис, доступный по ссылке и QR-коду
- Мобильный лендинг в фирменном стиле ЭКО-культуры
- Автоматическую генерацию брендированных фото с лицом пользователя
- Брендированный оверлей на итоговом фото: логотип, полоса с слоганом
- Возможность скачать результат напрямую с телефона (в т.ч. на iPhone)
- Защиту конфиденциальности: фото пользователей не хранятся, обрабатываются в памяти и удаляются сразу
- Исходный код проекта и инструкцию по самостоятельному деплою

## Этапы работ

### Этап 1. Аналитика и проектирование

**Состав работ:**
- Уточнение требований и сценариев использования (формат мероприятия, целевая аудитория)

- Выбор технического стека, архитектурные решения
- Описание API и структуры проекта
- Согласование состава базовых образов агрономов

**Результат:** согласованное техническое задание, описание архитектуры, пользовательский путь

**Стоимость: 30 000 ₽**

---

### Этап 2. Дизайн интерфейса

**Состав работ:**
- Дизайн мобильного лендинга в фирменном стиле ЭКО-культуры
- Проработка всех экранов: приветствие, загрузка фото, выбор персонажа, ожидание генерации, результат
- Брендирование: цветовая палитра `#1C4220` / `#7DC242`, шрифт Montserrat, логотип
- Дизайн брендированного оверлея на итоговом фото
- Адаптация под портретный формат смартфона (mobile-first)

**Результат:** финальный дизайн всех экранов, утверждённый заказчиком; макет брендированного фото

**Стоимость: 40 000 ₽**

---

### Этап 3. Разработка бэкенда (AI-модуль)

**Состав работ:**
- REST API на Python / FastAPI
- Интеграция библиотеки InsightFace: определение лица на фото пользователя, наложение на базовый образ агронома
- Настройка и тестирование AI-пайплайна (точность, скорость, обработка краевых случаев)
- Модуль брендированного оверлея: наложение логотипа, полосы с текстом слогана
- Архитектура без хранения данных: обработка в оперативной памяти (`BytesIO`), файлы на диск не пишутся
- Ограничения безопасности: максимальный размер файла, допустимые форматы, rate limiting

**Результат:** рабочий API-сервер, принимающий фото пользователя и возвращающий готовое брендированное изображение

**Стоимость: 130 000 ₽**

---

### Этап 4. Разработка фронтенда

**Состав работ:**
- Мобильный лендинг (Vanilla HTML / CSS / JavaScript, без фреймворков)
- Экран загрузки фото: открытие камеры или выбор из галереи
- Экран выбора персонажа: мужчина / женщина, варианты поз
- Экран ожидания с анимацией генерации
- Экран результата: отображение итогового фото, кнопка скачивания
- Реализация скачивания на iOS через Web Share API (стандартный «Сохранить в Фото»)
- Брендированное оформление всех экранов в соответствии с утверждённым дизайном

**Результат:** готовый фронтенд, корректно работающий на iPhone и Android в браузере без установки приложения

**Стоимость: 75 000 ₽**

## Условия

- **Оплата:** поэтапная — оплата каждого этапа до начала следующего
- **Срок разработки:** 3–4 недели с момента подписания и получения авансового платежа
- **Исходный код:** передаётся заказчику в полном объёме по завершении проекта
- **Гарантийная поддержка:** 30 дней после запуска — исправление ошибок без дополнительной оплаты
- **Хостинг:** аренда сервера оплачивается заказчиком отдельно (от ~700 ₽/мес.)
- **Базовые фото агрономов:** предоставляются заказчиком; требования к съёмке согласуются на этапе 1
