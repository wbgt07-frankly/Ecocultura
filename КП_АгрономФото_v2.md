# АгрономФото v2 — Обложка журнала TOMATO PEOPLE

## Концепция

Вместо простого face swap на фото агронома — пользователь попадает на **обложку журнала TOMATO PEOPLE** в роли эксперта по томатам. WOW-эффект достигается за счёт неожиданного результата и персонализации.

## Пользовательский сценарий

1. **Экран 1** — лендинг (без изменений)
2. **Экран 2** — загрузка фото + ввод имени
3. **Экран 3** — вопрос: *«Что ты больше всего ценишь в томатах?»*
   - 6–8 карточек с качествами (иконки/иллюстрации, без обложек)
   - Примеры: Сочность, Вкус, Польза, Аромат, Свежесть, ...
4. **Экран 4** — обработка (без изменений)
5. **Экран 5** — результат: персонализированная обложка журнала

## Логика выбора шаблона

```
качество (6–8 вариантов)
  × гендер (м/ж — определяется автоматически через InsightFace)
  = конкретный шаблон обложки
```

Итого: ~12–16 шаблонов обложек (по 2 на каждое качество).

## Определение пола

Используется атрибут `gender` из анализа лица InsightFace — автоматически, без вопросов пользователю.

## Наложение имени

Имя пользователя вписывается в шаблон обложки через Pillow в позицию поля «Имя» (рукописный/курсивный шрифт).

## Технические изменения относительно v1

| Компонент | v1 | v2 |
|---|---|---|
| Базовые фото | Агрономы в теплице | Шаблоны обложки журнала |
| Экран выбора | Карусель персонажей | Карточки с качествами томата |
| Имя | Нет | Вводится пользователем |
| Гендер | Не учитывается | Авто-определение через InsightFace |
| Оверлей | Зелёная полоса с логотипом | Имя на обложке |
